How the agent works

  1. Muse Spark watches each video: camera type, edits, on-screen clock, when the fireball shows, and landmarks a map could locate.
  2. SAM 3.1 follows the fireball frame by frame from the phrase "bright light" (run by a script, then cached).
  3. A person marks street lines and landmarks; the code fits each camera to them and to OpenStreetMap, so every pixel becomes a direction in the sky. This step is still human work.
  4. The agent, Muse Spark 1.3 calling tools in a loop, compares the cameras' planes of sight, solves, drops cameras, finalizes, writes the report or asks for missing evidence. Two planes from different sides cross in the trajectory; speed comes from each video's own frame times.
  5. The code checks what matters: it re-solves the chosen cameras and refuses unjustified choices, refuses any figure in the report that no tool returned, and stops the run for a person, who signs the report off or supplies the evidence. The published answer sits where the agent cannot read it; a separate script grades the run.

Built during the Meta Global AI Developer Hackathon with Muse Spark and SAM 3.1. Witness videos belong to their authors and are not redistributed here: only directions, times and camera sites rounded to about 100 m.
